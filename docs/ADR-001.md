# ADR-001 — Modular single-service client and managed backend
**Status:** Accepted for prototype | **Date:** 2026-10-29

**Context:** Student assignment requires explaining decomposition. Plant has one shared workflow, a small number of roles, and limited hosting budget.

**Decision:** Keep a single deployed web client backed by one managed Supabase project, organized into logical bounded contexts and a domain/application/adapter structure.

**Consequences:** Simple deployment and consistent transactions. Compromise: database is shared between bounded contexts; frontend `app.js` remains large and is a refactoring target. No claims of microservice isolation.
