# Integrated Steel Production and Operations Management System

## 1. Project Overview

This project aims to develop a web-based system for managing and monitoring steel production operations.

The system will focus on three main stages: melting, billet transfer, and rolling.

This project is developed as part of the Software Design and Architecture course.

## 2. Problem Statement

Steel production involves multiple connected operations. Tracking these operations manually can lead to errors, delays, and difficulties in monitoring production progress.

The proposed system aims to organize production data and improve the tracking of steel production activities.

## 3. Main Features

- Melting Management: Register and track steel melting operations.
- Billet Transfer Management: Record and monitor billet transfers.
- Rolling Management: Track rolling operations and finished steel production.
- Dashboard: Display production information and operational status.

## 4. Quality Attributes

- Maintainability: The system should be easy to modify and extend.
- Reliability: The system should handle operations and errors correctly.
- Data Integrity: Production records should remain accurate and consistent.
- Usability: The interface should be simple and easy to understand.

## 5. Initial Technology Plan

- Frontend: HTML, CSS, JavaScript
- Database: Supabase
- Hosting: Netlify
- Version Control: GitHub

## 6. Software Design and Architecture

The project will apply object-oriented programming principles, SOLID principles, and suitable design patterns.

The system architecture and design decisions will be documented and improved throughout the course.
